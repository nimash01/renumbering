Before executing the command, check the following.
1. The layout tabs must be renamed in order.
   eg: Should be renamed to 7,8,9,10 etc before running the command. Wrong order will result in errors in numbering the sheet.

2. "X OF Y" format must exist in the all sheets before renumbering. The number that's already existing is irrelevant. ( Since you will be copying the same layout for all your new sheets, this wont be a problem )

INSTRUCTIONS : 

1. Save the RENUMBERING.lsp to the desired folder.
2. Type "APPLOAD" in command.
3. Select "RENUMBERING.lsp" and select "load".
4. Then, run the command "RENUM" on the command line.
5. Input the total number of sheets and press enter.
6. Wait until the process is complete. ( ProgeCAD might freeze during the process )
